Diet-Youtube

A Chrome extension that replaces YouTube’s impulse Home with a queue-first reading surface. Watch later first. The algorithm stays one click away.

Get the source on GitHub Install guide

How it looks

Install (Load unpacked)

  1. Clone or download artvandelay/diet-youtube.
  2. Open Chrome → chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and select the folder that contains manifest.json.
  5. Open youtube.com while signed in.

What you get

  • Queue-first home: Watch later (or your chosen default playlist).
  • Feed only after an explicit tab click — one extra click from impulse.
  • Chronological Subscriptions plus new feeds (＋) — name one and add channels or playlists.
  • Icons + List layouts; Comfortable / Default / Dense Icons density.
  • Cache-first tab switches with background refresh.
  • Runs only in your browser — no Diet-Youtube backend.
